B8 Richer PPTX & Asset Downloads:
1. PPTX Generation (backend/app/services/export.py):
   - Slide count dynamically scales with duration: target = max(4, min(20, int(duration * 1.5)))
   - Varied slide layouts:
     * Standard Title + Bullets (body font >= 24pt)
     * Two-column comparison layout (Core Concept vs Practical Example cards)
     * Native Shape Process Diagram (MSO_SHAPE.ROUNDED_RECTANGLE + MSO_SHAPE.RIGHT_ARROW)
     * Overview & Key Points cards
   - Arabic RTL support: automatic Arabic character detection, PP_ALIGN.RIGHT and XML a:rtl="1"
   - Body font strictly >= 24pt (Pt(24) default, Pt(22) for dense slides)
   - Note on image rendering: LibreOffice headless is not installed in the Windows environment, but PPTX generation is verified (42,988 bytes valid binary presentation).
2. Video Script & Asset Downloads:
   - GET /api/ai/videos/{video_id}/script-docx -> true Word (.docx) with scene breakdown
   - GET /api/ai/videos/{video_id}/script-pdf -> branded PDF with metadata and scenes
   - GET /api/ai/videos/{video_id}/subtitles-srt -> valid standard WebVTT/SRT subtitles
   - UI buttons wired into Video result viewer in AITools.jsx
3. Reports Export:
   - GET /api/reports/sessions/{session_id}/export.csv -> session summary + attendee log
   - GET /api/reports/sessions/{session_id}/export.pdf -> branded session summary + emotion distribution + AI teaching recommendations
   - UI buttons wired into Reports.jsx
